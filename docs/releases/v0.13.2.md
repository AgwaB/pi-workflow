# @agwab/pi-workflow 0.13.2

`0.13.2` is the publishable successor to the protected but unpublished `0.13.0` and `0.13.1` source tags. It includes the same product changes plus GitHub Actions parser, Linux peer-installation, and loaded-suite timing corrections proven with Node 24.19.0 and npm 11.17.0 on Linux before release.

## Highlights

- Adds stable, user-facing `final-report.md` completion reports for the bundled deep-research, deep-review, spec-review, and impact-review workflows while preserving their legacy detailed report artifacts.
- Upgrades bundled `pi-web-access` compatibility to 0.24.2, preserves legacy `web_search`, `fetch_content`, `get_search_content`, and read-only `code_search`, and adds normalized workflow search/fetch/source tools.
- Adds run-scoped durable web-source cards, batched fetch/read operations, bounded continuation, cross-worker replay, cancellation, provider attribution, and direct-safe public HTTP fetching.
- Fixes deep-review structured-action schema failures and hardens finding identity, lineage, reviewer ownership, deduplication, challenge, partition, and final renderer reconciliation.
- Extends fail-closed ownership and lifecycle reconciliation to spec-review, impact-review, and deep-research final reporting.
- Prevents authenticated or sensitive web requests from entering shared caches, redacts secrets from query strings and encoded fragments, and hardens private atomic cache/event persistence.
- Hardens canonical request hashing for special object keys and makes workflow output-section scanning depth-aware.
- Strengthens package closure, packed-package E2E coverage, modern protected-tag ruleset verification, npm dist-tag and provenance verification, and concurrent release validation.
- Makes GitHub runner npm configuration parse-safe and private, and explicitly installs the matching Pi TUI peer required by fresh-process web-provider validation.

## Compatibility

No intentional public API break is included. Existing legacy web tool names and detailed report artifacts remain available. Invalid or contradictory workflow lineage, ownership, or verifier metadata that could previously pass incompletely now fails closed.

Node.js `>=22.19.0` remains required. Consumers updating to `@agwab/pi-workflow@0.13.2` should refresh their lockfiles; the package bundles `pi-web-access@0.24.2` and continues to depend on `@agwab/pi-subagent@^0.5.1`.
